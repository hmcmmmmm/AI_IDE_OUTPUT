## 四、会议看点

- **目标函数换了三次**：FLOPS → TPS/MW → 2026 年分裂成 TPS/MW（吞吐经济学）与 TPS/user（交互性）两个互不兼容的指标。
- **Day1 GPU 场是焦点**：NVIDIA Rubin、AMD MI400（架构 + 系统两讲）、Intel Crescent Island 同日登场。
- **内存墙被量化成可结算的账**：技术侧 3×/2yr vs <2×/2yr；财务侧内存占 AI 芯片 BOM 从 52% 升到 63%。
- **HBM 的 scaling 从 DRAM 问题变成封装问题**：12Hi→16Hi 高度只许 +7.6%，≥20Hi 必须混合键合。
- **CPU 被重新估值**：Vera、Diamond Rapids、Arm AGI、MONAKA、IBM Z 双指令集、Wildcat Lake（Intel 首次用 UCIe 降本）。
- **自研 ASIC 第二梯队集体亮相**：Google TPU v8、Microsoft MAIA 200、Meta MTIA 400、OpenAI Jalapeño、Cerebras CS-4、SambaNova SN50、NVIDIA LPU。

深度展开见 `06_深度分析报告/`，逐条证据见 `05_渠道图文归档/`。
