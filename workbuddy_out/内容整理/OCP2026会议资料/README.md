## 三、内容看点

**主论坛（含中英文技术报告）**
- 《GW-Scale Open AIDC 框架技术报告 v1.0》——业界首份 GW 级开放智算中心框架，围绕算力、高速互连、存储、大功率供电、全栈液冷五大支柱给出开放架构与实施路径。
- 阿里云、字节跳动、浪潮信息、庆虹电子、伟创力、晶丰明源、Astera Labs 等的主论坛演讲。

**六个技术论坛（主题按官方论坛顺序对应，文件名为源站命名）**
1. 数据中心基础设施：Retimer / AEC / 448G 高速铜缆 / 硅光 OCS / 万卡高可用网络
2. 算力电力协同：800V 直流供电架构、多相电源、IBC、垂直供电
3. 可持续计算：两相液冷、低 GWP 制冷剂、开源固件与机架级管理
4. 开放系统设计：CXL / UALink / DASE、UMX 统一内存、智能体原生 GPU 架构
5. GW 级开放智算中心：SuperPod、原生液冷、预制化 AI 工厂
6. 智算固件开发：AI BMC、OpenBMC 移植、RAS API 标准、可信固件
