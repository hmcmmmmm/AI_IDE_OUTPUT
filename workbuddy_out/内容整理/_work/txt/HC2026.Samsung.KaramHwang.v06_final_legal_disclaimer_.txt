The Need for New Memory Solutions
The de facto memory solution to support AI Inference: HBM
• High power consumption
• Complex packaging 
To achieve lower cost, various advancements have been made in AI Inference: 
• Efficient LLM architecture 
• Smaller size models
A new memory form factor is required →LP-PIM
• Higher bandwidth (compared to normal LPDDR)
• Lower overall power consumption at system level

Appendix – Terms and Functions
•
The exact function of the terms and functions are listed in the table below:
Term
Description
Source Register File (SRF)
Register used to buffer input activation vectors as input for a GEMV operation (input register)
Scale Register File (ScRF)
Register used to buffer scale factors to multiply with associated weight values for a GEMV operation
Vector Register File (VRF)
Register used to store partials sums during accumulation (output register)
Instruction Register File (IRF)
Register used to store 16b PIM instruction (total of 64 instructions can be stored)
Configuration Register File
Register used to configure various PIM block settings (ex : MAC precision datatype, bit-width) 
Read PIM (RDP)
Reads a 32B value from the designated register in a single PIM block
Write PIM (WRP)
Writes a 32B value to the designated register in a single PIM block
Write PIM Broadcast (WRPB)
Writes a 32B value to the designated register in multiple PIM blocks
PIM Execution Read (PIMX-RD)
Performs a designated operation in all PIM blocks by reading values from DRAM
PIM Execution Write (PIMX-WR)
Writes the value of the designated register in each PIM block to DRAM
