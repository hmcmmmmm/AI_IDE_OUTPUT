PCIe
Device Memory
In multi-GPU systems, memory copies between two 
device memories are common. 
Example:
1. GPU 0 writes data to GPU 1 device memory
2. GPU 0 writes flags to host memory
3. CPU reads flags from host memory
4. CPU launces CUDA kernel on GPU 1
PCIe P2P support is required for CUDA—avoids CPU 
involvement and extra copy to host memory
• Various root-complex and end-point configs
• P2P traffic at full speed for128-byte packets
• Root complex to maintain standard PCIe ordering rules
PCIe P2P communication – another CUDA specific requirement
