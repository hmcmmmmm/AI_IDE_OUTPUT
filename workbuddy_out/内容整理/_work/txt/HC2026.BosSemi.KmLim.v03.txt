BOS Semiconductors│14
System Layer
Description
Functional Domain
The UCIe AXI Bridge integrates an Address Protection Unit (APU) on both the inbound and 
outbound paths, providing address translation and access protection for all transactions.
Addressing
Eagle-N supports operation as both a primary chiplet and a secondary chiplet. When operating 
as a secondary chiplet, its firmware can be downloaded from the primary chiplet over the D2D 
interface.
Boot
An integrated 64-bit system time counter supports Open Chiplet Time Synchronization (OCTS). 
The counter can be configured to operate as either the primary counter or the secondary counter.
System Time Management
Eagle-N provides secure interoperability with OCA-compliant chiplets through authenticated 
boot, lifecycle-based security, and AXI-based access control.
Security
The UCIe block supports MSI-based inter-chiplet interrupts through a built-in doorbell 
mechanism. The Safety Entity supports dedicated Fatal and Non-Fatal Error/Status interrupt 
signaling between chiplets.
Interrupts
Eagle-N implements one OCCT channel for cross-trigger signaling and provides full OCCT 
connectivity as a leaf chiplet. ETR trace data can be transferred across the UCIe channel and 
dumped into remote memory.
Design for Debug
IEEE 1838 STAP is implemented to support daisy-chained ATE-mode BIST execution and scan 
dump across multiple dies. Open Chiplet Packetized Scan (OCPS) is not implemented.
Design for Test
Eagle-N supports a one-to-one Safety Primary/Secondary Chiplet configuration and OCA-based 
FuSa messaging, including periodic channel checks and CRC.
Functional Safety

Eagle-N Interconnect Architecture
Interconnect Architecture
•
High bandwidth requirements 
•
Memory bandwidth decides AI model performance rather 
than compute performance in many AI models 
 
•
Architecture Overview 
•
Hierarchical NoC architecture consisting of a high-bandwidth 
main fabric and subsystem-specific local buses, enabling 
scalable heterogeneous subsystems. 
 
•
High-Bandwidth Interconnect 
•
1024-bit @ 800 MHz (dual-channel) main fabric and 512-bit 
@ 1 GHz (four-channel) on-chip NPU fabric. 
 
•
Memory Subsystem 
•
Up to 204 GB/s memory bandwidth through 12-channel 
LPDDR5X with channel interleaving. 
 
•
Efficiency Optimization 
•
High bandwidth utilization under burst workloads through 
reorder buffers and transaction scheduling.
