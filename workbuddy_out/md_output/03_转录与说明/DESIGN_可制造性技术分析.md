# DESIGN.md — 深空石墨

## 0. 设计依据

未命中学术 / 咨询 / 红金政务三类预设分支，走通用设计原则 + 用户选定的「A · 深空石墨」色板。
场景：技术分析汇报，受众为研发管理层，页面以「发给领导自己看」为主 → **高密度、自解释、单页可独立成篇**。

---

## 1. 画布与母版（具体 px）

画布 1280 × 720。页面 padding：上 40 / 下 32 / 左右 72。

| 母版区 | 垂直位置 | 高度 | 内容规则 |
| :--- | :--- | :--- | :--- |
| **A · 标题块** | 0–120 | 120（含上 padding 40） | 主标题 36px bold，左侧 3px 金色竖线；右上角小标为章节名（14px，透明度 0.45） |
| **B · 内容区** | 120–660 | 540 | 全部正文、矩阵、图表、卡片 |
| **C · 页脚条** | 660–720 | 60 | 左：`可制造性评估维度解析`（14px，透明度 0.35）；右：`NN / 16`（14px，Georgia，透明度 0.45） |

内容可用宽度 = 1280 − 72×2 = **1136px**；可用高度 = 720 − 40 − 32 = **648px**，其中 B 区 540px。

封面 / 章节扉页 / 结束页使用自定义版式，省略 C 区。

## 2. 颜色系统（4 hex + 文本透明度）

| 角色 | 值 | 用途 | 面积占比 |
| :--- | :--- | :--- | :--- |
| 主色 · 深空底 | `#0E1420` | 全页背景、章节扉页底 | ≤ 60% |
| 辅色 · 石墨面板 | `#1B2432` | 卡片、栏底、矩阵底、图表背景 | ≤ 30% |
| 强调 · 琥珀金 | `#C8A15A` | 关键数字、焦点标注、竖线、当前项 | ≤ 10%（Hero 页 15–20%） |
| 文本 · 冷白 | `#E8EDF3` | 全部文字、矩阵实心点、图表主线 | 剩余 |

**次级文本**：一律用 `rgba(232,237,243,0.55)`；三级注释 `rgba(232,237,243,0.38)`。
**分隔线**：`rgba(232,237,243,0.10)`，1px。
**空心点 / 弱信号**：`rgba(232,237,243,0.22)`。

不引入第五个 hex。图表轴色用 `#E8EDF3`，系列色用 `#C8A15A` 与 `rgba(232,237,243,0.55)` 对应的实色 `#8A99AC`——仅在 Chart 组件内部允许，属图表内置色，不进入版面色池。

**渐变与半透明**：本项目**禁用渐变**（深色底上渐变易出现色带），仅用纯色 + 半透明叠加。面板叠加用 `rgba(232,237,243,0.04)`，高亮块用 `rgba(200,161,90,0.10)`。

**色彩节奏**：Hero 页（P1/P7/P12/P16）金色占比 15–20%；Supporting 页（P4/P6/P8/P9/P11/P14/P15）金色 ≤ 5%，仅用于焦点数字与当前项。

## 3. 字体系统

两套家族：

| 章节大字 | 44 | bold | 1.2 | 2 | YaHei | P3/P5/P10/P13 |

| 巨型锚点 | 120–200 | normal | 1.0 | −2 | Georgia | P7 的 200×、P12 的 3–12、P16 的 30/60/90 |

| 数据数字 | 28–40 | normal | 1.1 | 0 | Georgia | 成本倍数、评分 |

## 4. 信息密度（本项目为「高密度自解释」型）

覆盖默认留白上限，改为：

| 页面类型 | 正文字数下限 | 主视觉占 B 区 | 留白上限 |
| :--- | :--- | :--- | :--- |
| 内容页 · 矩阵/结构 | 220 | ≥ 55% | 18% |
| 内容页 · 图表+洞察 | 150 | ≥ 50% | 20% |
| 章节扉页 | 40 | ≥ 45%（巨型序号） | 55% |
| 封面 / 结束 | 45 / 150 | ≥ 40% | 45% / 40% |

容器填充率 ≥ 85%；卡片尾部元素（结论条 / 标签）用 `marginTop: 'auto'` 钉底。

---

## 5. 视觉元素白名单

- **允许**：1px 发丝线、3px 金色竖线、实心/空心圆点（矩阵）、水平条形（打分）、细柱（风险）、台阶方块、超大序号暗纹。
- **禁止**：渐变、投影、圆角 > 6px 的胶囊、图标堆叠、装饰性小图、emoji。
- **矩阵点阵**：实心 = 强证据（r=9，`#E8EDF3` 或 `#C8A15A`）；空心 = 弱证据（r=8，描边 2px `rgba(232,237,243,0.22)`）；极小灰点 = 基本无效（r=4，`rgba(232,237,243,0.12)`）。
